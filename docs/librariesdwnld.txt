install the same packages in terminal with:

Step 1 copy the following in separate commands into a terminal:

python -m venv C:\venvs\modus-golf

C:\venvs\modus-golf\Scripts\Activate.ps1

python -m pip install --upgrade pip setuptools wheel

pip install -r requirements-dev.txt

Step 2:
make sure your .gitignore file looks like this:
# Virtual environment
venv/

# Python cache
__pycache__/
*.pyc

# VS Code
.vscode/

# OS files
.DS_Store
Thumbs.db

*.pt
----------------------------------------------------------------------------------------------
pushing new vs  code to github:
git status
git add .
git commit -m "Describe what you changed"
git push
-------
enter github on pi5 os:
cd ~/MODUS-Golf
-------
after pushing updated code to git hub update github on pi5:
git pull
--------
activate virtual environment:
source venv/bin/activate
------
deactivate environment:
deactivate
--------
shutdown board:
sudo shutdown now
