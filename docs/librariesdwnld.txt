
install the same packages in terminal with:

Step 1 copy the following in separate commands into a terminal:

python -m venv C:\venvs\modus-golf

C:\venvs\modus-golf\Scripts\Activate.ps1

python -m pip install --upgrade pip setuptools wheel

pip install -r requirements-dev.txt


Step 2:
make sure your .gitignore file looks like this:
# Virtual environment
venv/

# Python cache
__pycache__/
*.pyc

# VS Code
.vscode/

# OS files
.DS_Store
Thumbs.db

*.pt






pi5os code:
# one-time system packages
sudo apt update
sudo apt install -y git python3-venv python3-picamera2

# get the code
git clone <your-repo-url>
cd MODUS-Golf

# create the environment and install the Pi requirements
python3 -m venv --system-site-packages venv
source venv/bin/activate
pip install -r requirements-raspi.txt

# allow serial port access for the radars (log out and back in after)
sudo usermod -aG dialout $USER

# run it
python main.py
